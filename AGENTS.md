# Инструкции для Codex (картинки)

Репозиторий общий с Claude. Claude делает сайты в `projects/<имя>/`, ты делаешь картинки.

## Задача
1. Открой `projects/<имя>/IMAGES.md`.
2. Для каждой строки таблицы сгенерируй картинку по промпту из раздела «Промпты».
3. Сохрани в `projects/<имя>/public/images/` под точным именем из таблицы, заменив заглушку. Соблюдай размер и пропорции.

## Правила
- Работай в своей ветке `codex/images-<имя>`, не в `claude/*` и не в `main`.
- Меняй только файлы в `projects/<имя>/public/images/`. Код сайта, `IMAGES.md`, `.claude/`, `.mcp.json` не трогай.
- Не переименовывай файлы и не добавляй новые без запроса.
- Если картинку нельзя сгенерировать, оставь заглушку и напиши об этом в описании коммита.
- Закончив, сообщи названия ветки и список заменённых файлов.
