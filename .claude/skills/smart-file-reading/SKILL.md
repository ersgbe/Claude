# Smart File Reading

- Сначала искать (`Grep`, `Glob`), затем читать нужный участок (`offset`/`limit`).
- Большие файлы читать частями, файл после правки не перечитывать.
- Файлы `references/` у скиллов открывать только когда они нужны.
