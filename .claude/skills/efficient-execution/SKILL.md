# Efficient Execution

## Token Efficiency
- Не повторять уже известное, не пересказывать файлы и вывод инструментов.
- Выводы команд ограничивать (`head`, `tail`, фильтры), логи читать по ошибкам.
- Независимые вызовы инструментов делать параллельно.
- Ответ пользователю короткий: результат, затем пункты.

## Minimal Execution
- Делать только то, что нужно для задачи. Без лишних файлов, рефакторинга и "заодно".
- Не запускать долгие и повторные команды, если результат уже известен.
- Не спрашивать то, что можно решить разумным значением по умолчанию.

## Smart File Reading
- Сначала искать (`Grep`, `Glob`), потом читать нужный участок (`offset`/`limit`), не весь файл.
- Большие файлы и данные скиллов читать частями. Не перечитывать файл после правки.
- Справочные файлы скиллов (`references/`) открывать только когда они нужны.

## Selective Testing
- Проверять только изменённое: затронутый компонент, страницу или тест, а не весь проект.
- Для сайта: сборка и просмотр изменённой страницы. Полный прогон только перед публикацией.
- Если проверку не запускал, прямо сказать об этом.
