# Token Efficiency

- Не повторять известное, не пересказывать файлы и вывод инструментов.
- Выводы команд ограничивать (`head`, `tail`, фильтры).
- Независимые вызовы инструментов делать параллельно.
- Ответ пользователю короткий: результат, затем пункты.
