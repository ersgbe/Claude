В Telegram Web был собран индекс из 109 отображённых контейнеров сообщений, включая служебные и архивные записи. В двух навигаторах обнаружено 18 уникальных ссылок на посты. Целевое чтение охватило два закреплённых навигатора и доступный текст ключевых публикаций. Промежутки между идентификаторами и отсутствие части материалов в интерфейсе не позволяют установить полноту архива. Два ролика разобраны по автоматическим субтитрам. Остальное медиа отмечено в реестре. Практические примеры для продажи сайтов и метрики эксперимента добавлены для применения идей к конкретной услуге. Цифры автора следует считать примерами из его практики.
